**パネル作者さんにご協力のお願い**

**このツールは開発途中です。特に画像からパネルを作る機能については「PSD・XCFを読みこんだらほぼBVEのパネルが完成する」レベルの実装を目指しているところです。そのためには仕様を決めなければなりませんが、他の作者さんがどのような造りでパネルを作っているのか全く不明なので、どういう形で実装させるか悩んでいるところです。もうしばらく悩んでおきますので、PSD・XCFを実際に提供していただける方がいればご遠慮なく連絡をください。（なおXCFはClaudeが簡易的に作成したもので読み込みを試したのみで、現状運転台パネルとしての完成品を読みこんだことはありません）**

BVE Trainsim 5 / 6 の運転台パネルファイル（`BveTs Instrument Panel 2.00 / 2.01`）を、画面で見ながら編集するツールです。画像を読みこんで部品を作ることもできます。

## 0.4.2α での変更

- **SVG の読み込み**: 画像と同じように、SVG をドロップしたりメニューから読み込んだりできます。BVE は SVG を読めないので、倍率を聞いて PNG にしてから置きます
- **画像を 4 隅で変形して貼りこむ**: 正面から描いたモニタなどの画像を、パネルの斜めの面に合わせて変形して置きます。常点灯画像と DigitalNumber（コマ割済）に使えます。DigitalNumber は 1 コマずつ変形します
  - オブジェクトの追加のメニューから選ぶか、画像をドロップしたときに選びます
  - 変形の画面では、パネルの絵の上で 4 隅をドラッグして合わせます。数字でも入れられます
  - 元の画像と 4 隅はパネルファイルに覚えます。一覧の行には「変形」の印が付きます
  - 右の欄の「画像を変える…」で元の画像を選び直すと、同じ 4 隅で変形し直します。「4 隅を直す…」で 4 隅を決め直せます
- **パネルファイルの一部を取り込む**: モニタなどの部分だけを書いたパネルファイルを、今のパネルの最後に 1 つのグループとして足します（ファイル → パネルファイルの一部を取り込む…）。画像はパネルのフォルダにコピーします

詳しくは [機能の詳細](docs/機能の詳細.md) を見てください。

## 0.4.1α での変更

- **パネル画面の背景**: 表示 → 背景 で、グレー・市松模様（透明）・グラデーション・ピンクから選べます
- **画像のプレビュー**: オブジェクト一覧の下に、選んだオブジェクトの昼・夜の画像を出します（透明な所は市松模様）。ファイル名と大きさも出します。見出しをクリックすると畳めます
- **見た目**: Windows 11 風の見た目（Fluent）にし、ボタンや一覧の余白を詰めました

## 0.4α での変更

- **GIMP の XCF に対応**: PSD と同じように、XCF のレイヤーを読み込めます。使える場面は次のとおりです
  - 「PSD・XCF から読み込み」（レイヤーごとに役割を選ぶ）
  - 「画像からパネルを作る」のレイヤーの振り分け
  - 画像のドロップ（常点灯・デジタル数字）
  - デジタル数字のコマ（レイヤーを 1 コマずつ）
  - 指針のふた
  - 「切り抜き元から更新」
  - 読めるのは 8bit の RGB・グレースケールで、GIMP 2.8・2.10・3.x の XCF（版 0〜23）です。16bit 以上とインデックスカラーは、保存し直すよう知らせます
  - 重ね方は GIMP に合わせています（リニアで混ぜる描画モードも同じ色になるようにしました）。非破壊フィルターと ICC プロファイルは再現しないので、知らせを出します
  - 詳しい対応範囲は [XCF対応.md](docs/XCF対応.md) を見てください
- **PSD: グラデーション塗り**: グラデーションの塗りつぶしレイヤー（線形・円形・角度・反射・菱形）を、近似して再現します。補間方法（クラシック・滑らかに・リニア・知覚的）にも合わせます
- **PSD: 調整レイヤーを 4 種類追加**: 階調の反転・2 階調化・ポスタリゼーション・露光量
- **Photoshop・GIMP と見た目が変わるものの知らせ**: 読み込み画面とレイヤーの振り分け画面では、次のように出します
  - そのまま再現できる注記は青い字で出します
  - 見た目が変わるものがある行には、赤い字の短い印（△近似・×非対応）を付け、行の背景を薄い赤にします
  - 印にカーソルを載せると、詳しい中身が出ます
  - 読み込んだあとの注意も「△ 近似して再現」「× 再現不可」に分けて出します
  - フォルダの描画モード（通過以外）は再現しないので、× として知らせます
- **PSD: フォルダの開閉**: Photoshop で開いていた・閉じていたフォルダは、読み込み画面でも同じ状態で出します
- **PSD: 大きいファイル**: レイヤーの多い PSD での検索や一括変更を速くしました
- **新規パネル**: ベース画像を選ばせず、起動したときと同じ、まっさらな状態から始めるようにしました。保存前のパネルに画像を読み込むときは、先に保存先を聞きます
- **不具合の修正**: PSD の読み込み画面で、一括変更したときに入れ子のフォルダの役割の表示が変わらなかったのを直しました

## 0.3.1α での変更

- **バリエーション展開: 分かれたオブジェクトの知らせ**: 並び位置や値の違いで 2 つに分かれたままのオブジェクトを、左下の「問題」の欄に緑の「分かれ」の印で知らせます（警告の件数には数えません）。ダブルクリックでそのオブジェクトに移り、カーソルを載せると、どのキーがどのバリエーションでどう違うかが出ます。取り込んだマスターだけでなく、手で作ったマスターでも見つけます
- **「既存のパネルからマスターを作る」の基準パネル**: 「土台」と呼んでいた先頭のパネルを「基準パネル」と呼ぶようにし、役割（マスターの並び・1 行目・コメントとグループ、切り抜き元や PSD とのつながりは基準パネルのものを使う）を窓に書きました。各行の「基準にする」ボタンで、基準パネルを選び直せます
- **問題の欄の大きさ**: 一覧と問題の欄の間の帯をドラッグすると、問題の欄の高さを変えられるように直しました。「問題」の見出しもドラッグで高さを変えられます（動かさずにクリックすると、今までどおり畳む・開く）
- **RealAnalogGauge: 設定が複数ある車両**: Ats32 用と Ats64 用のように設定ファイルが複数ある車両では、全部読みます。表・振動の書き込み、針の追加・取り外しは、全部の設定の同じ針にそろえます（片方だけ古くならないように）。主と内容が違う針・片方にしかない針は、問題の欄で知らせます
- **RealAnalogGauge: 動かして確かめるの速さ**: 速さの候補を、針の表の範囲に合わせて決めるようにしました（範囲が広い計器ほど速く。圧力の計器は、さらに 3 倍）。圧力計などで、全体を動かすのに時間がかかりすぎていたのを直しました
- **RealAnalogGauge: 止めたあとの揺れ**: 「0 からゆっくり動かす」を止めても、低速の振動で針が揺れ続けていたのを直しました。振動は動かしている間だけ出て、止めると針は表の値のまま止まります
- **動作プレビュー: 「針を止める」ボタン**: 減衰比が 0 の針など、揺れ続ける針を、今の値の角度で止められます

## 0.3α での変更

- **RealAnalogGauge 対応**: ATS プラグイン RealAnalogGauge の、等間隔でない目盛りに合わせた針の角度と、低速の針の振動を、動作プレビューで再現します。表（入力値と角度）の編集、0 からゆっくり動かして確かめる、標準の針との相互変換もできます
- **操作の改善**
  - 重なったオブジェクトを、右クリックの一覧から選べます。選んでいるオブジェクトは、上に別のものが重なっていてもドラッグで動かせます
  - 「オブジェクトの追加 → 画像を読み込む…」（画像をドロップしたときと同じく、読み込み方を選べます）
  - 追加したオブジェクトは、選んでいるもののすぐ下に、同じレイヤー・グループで入ります
  - レイヤーをそろえる（そろえる先を選べます）。左の一覧の下に、レイヤー・グループのボタンを置きました
  - デジタル数字のテスト画面で、BVE での見え方を拡大できます
  - 選んだオブジェクトの枠: 動かせるときは黄色の実線、位置ロックで動かせないときは黄色の点線
  - 言葉: 「計器」を「オブジェクト」に、「蓋」を「ふた」にしました
- **使いやすさ**: 保存のメッセージは、.bak を作ったときだけ知らせます。下のメッセージ欄は、カーソルを載せると全文を読めます。ヘルプから説明書とショートカットキーの一覧を開けます
- **不具合の修正**
  - 「既存のパネルからマスターを作る」で、書き方だけ違う同じオブジェクトが 2 つに分かれたり、名前だけ違うオブジェクトが 1 つにまとめられたりしていたのを直しました
  - 値に改行が入ると、保存で値が途中で切れていたのを直しました
  - 保存の途中で失敗すると、ファイルが壊れることがあったのを直しました（一時ファイルに書いてから差し替えます）

## 動作環境

- Windows 10 / 11（64bit）
- .NET 10 デスクトップ ランタイム（入っていなければ、起動したときに Windows が入手先を案内します）
- BVE Trainsim 5 / 6 のパネルファイル（Tilt・StopPin・Perspective のキーは BVE 5.8 以降・BVE6。書式 2.00 のパネルでも使えます）

## はじめかた

1. 配布ファイルを好きなフォルダに展開します（`needles`・`needle_E217` フォルダも exe と同じ場所に置いたままにしてください）
2. `BvePanelEditor.exe` を起動します
3. ファイル → 開く で、パネルファイル（.txt / .cfg）を開きます。車両ファイル・シナリオファイルからたどって開くこともできます。パネルファイルを exe や画面にドラッグ＆ドロップしても開けます

開いたばかりのときは「位置ロック」がかかっていて、オブジェクトを不意に動かさないようになっています。パネル画面左上の「🔒 位置ロック中」か Ctrl+L で解除します。選んだオブジェクトの枠は、動かせるときは黄色の実線、動かせないときは黄色の点線です。

## 画面

- **左**: オブジェクトの一覧（ファイル順／レイヤー順）と、問題の一覧
- **中央**: パネル画面（ドラッグで配置、ホイールで拡大、スペース＋ドラッグか右・中ドラッグで表示を動かす、Ctrl+0 で表示範囲の全体を表示。操作の案内は画面の右下）と、パネルファイルのテキスト
- **右**: 選んだオブジェクトのプロパティと、動作プレビュー（速度・圧力などを動かして針や表示灯の動きを確かめる）

## できること

- **見ながら編集**: オブジェクトのドラッグ・矢印キーでの移動、プロパティ欄での値の書き換え、テキストの直接編集。どれも Ctrl+Z で元に戻せます
- **書式を崩さない保存**: コメント・空行・文字コード・改行はそのまま残し、変えた所だけ書き換えます。最初の保存では元のファイルを `.bak` に残します
- **オブジェクトの追加**: 表示灯・指針・デジタル数字・円形ゲージ。標準の針（速度計・圧力計・時計）は回転の中心や角度まで入った状態で置けます。画像・PSD・XCF をドロップすると、常点灯画像か、デジタル数字（コマ割済の画像、または 1 コマずつの画像からコマ割を作る）として読み込めます。デジタル数字はテスト画面で 1 コマの高さを確かめられます
- **整理**: 複数選択・整列・グループ化・レイヤーの上げ下げ・名前付け。一覧はファイル順／レイヤー順のボタンで並べ替え。一覧での表示／非表示（パネルくんの画面だけ）と、コメントアウト（BVE でも非表示）
- **動作プレビュー**: 状態量をスライダーで動かし、針の揺れ・表示灯・数字・ゲージを確かめます。昼⇔夜の切り替え、Tilt（傾き）の表示もできます
- **作る**:
  - 新規パネル（まっさらな状態から）
  - 画像からパネルを作る（昼・夜 × 消灯・点灯の 4 枚の画像から、表示灯を切り抜く。PSD・XCF ならレイヤーを振り分けて使えます。窓ガラス・窓枠などの重ねる画像や、スイッチ・カバーの変化を切り抜く部品用の画像も扱えます）
  - PSD・XCF から読み込み（レイヤーごとに役割を選ぶ。対応範囲は [PSD対応.md](docs/PSD対応.md)・[XCF対応.md](docs/XCF対応.md)）
  - 指針のふたを作る（パネルの画像から軸のふたを切り抜く）
  - 表示範囲や数字の 1 コマの高さを画像から計算
- **バリエーション展開**: 全部入りのパネル（マスターパネル）を 1 枚作り、オブジェクトごとに入るバリエーション（路線など）を決めて、バリエーションごとのパネルファイルを書き出します。既存のバリエーション別パネルからマスターを作ることもできます。どのバリエーションに入るかは、パネルファイルにコメント `; @group 名前` 〜 `; @end` で書きます
- **RealAnalogGauge 対応**: ATS プラグイン [RealAnalogGauge](https://bvews.jpn.org/materials/real-analog-gauge/)（BVE Workshop 作。目盛が等間隔でない計器の針と、低速の針の振動）の動きを、動作プレビューで再現します（計算は RealAnalogGauge のソース（MIT License）を参考に移植しています。著作権表示は THIRD-PARTY-NOTICES.txt）。設定は車両ファイルの ATS からたどって探すか、手で選びます。一覧では「RAG」の印で分かります。右の欄で 0 からゆっくり動かして針の動きを確かめられ、針の動きの表（入力値と角度）・振動を編集でき、パネル画面のクリックで針の向きを決められます。標準の針と RealAnalogGauge の針は、相互に変換できます
- **問題の一覧**: 画像がない・状態量の書き間違い・使えないキーなどを知らせます。BveEX の状態量（ats256 以上）は「BveEX 対応オブジェクト」として別の印で出します。1 行目の文字コードの指定と中身が違うファイルは、中身の文字コードで読み書きし、警告を出します

細かい動きと主な操作キーは [機能の詳細](docs/機能の詳細.md) を見てください。
`sample` フォルダに、画像・PSD からパネルを作る手順を試せるサンプルと手順書（`sample/Readme.txt`）があります。

## 気をつけること

- 画像の書き出し（表示灯の切り抜き・ふた・PSD・XCF からの書き出しなど）は、PNG を上書きすることがあり、Ctrl+Z では戻せません。上書きの前には確認を出します
- パネルファイルを保存しないまま閉じる（終了・別のファイルを開く・新規）と、そのパネルのために新しく書き出した画像（とそのために作ったフォルダ）をゴミ箱に送るか聞きます。すでにあった画像を上書きしたものは対象にしません
- パネルくんはパネルファイルに、グループ・PSD・XCF や切り抜き元とのつながりを `;` で始まるコメントで書き込みます（BVE は読み飛ばします）
- 「指針を置く」の一覧は exe と同じフォルダの `needles.txt` に保存します。書き込みできないフォルダ（Program Files など）に置くと保存できません

## 困ったとき

- 予期しないエラーが起きたときは、詳しい内容を `%AppData%\BvePanelEditor\logs` に、まだ保存していない内容の控えを `%AppData%\BvePanelEditor\recovery` に書きます。不具合を知らせるときは、ログのファイルを添えてください
- 表示の設定は `%AppData%\BvePanelEditor\settings.txt` にあります。消すと初期の設定に戻ります
- 版とクレジットは、ヘルプ → バージョン情報 でも見られます
