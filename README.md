# パネルくん

<img width="1748" height="1078" alt="AnimationN2" src="https://github.com/user-attachments/assets/66cf963d-0a86-4bc4-96be-6e7e73711db5" />


BVE Trainsim 5 / 6 の運転台パネルファイル（`BveTs Instrument Panel 2.00 / 2.01`）を、画面で見ながら編集するツールです。画像を読みこんで部品を作ることもできます。

- 版: **0.3α**（試験版です。大事なパネルは、コピーをとってから使ってください）
- ライセンス: MIT License（[LICENSE](LICENSE)）。使っているライブラリ・同梱素材は [THIRD-PARTY-NOTICES.txt](THIRD-PARTY-NOTICES.txt)
- ダウンロード: [Releases](https://github.com/ntfiv/BvePanelEditor/releases) の `BvePanelEditor-0.3alpha-win-x64.zip`（標準の針・サンプルはこちらに入っています。このリポジトリのソースには入っていません）

## 0.3α での変更

- **RealAnalogGauge 対応**: ATS プラグイン RealAnalogGauge の、等間隔でない目盛りに合わせた針の角度と、低速の針の振動を、動作プレビューで再現します。表（入力値と角度）の編集、0 からゆっくり動かして確かめる、標準の針との相互変換もできます
- **操作の改善**
  - 重なったオブジェクトを、右クリックの一覧から選べます。選んでいるオブジェクトは、上に別のものが重なっていてもドラッグで動かせます
  - 「オブジェクトの追加 → 画像を読み込む…」（画像をドロップしたときと同じく、読み込み方を選べます）
  - 追加したオブジェクトは、選んでいるもののすぐ下に、同じレイヤー・グループで入ります
  - レイヤーをそろえる（そろえる先を選べます）。左の一覧の下に、レイヤー・グループのボタンを置きました
  - デジタル数字のテスト画面で、BVE での見え方を拡大できます
  - 選んだオブジェクトの枠: 動かせるときは黄色の実線、位置ロックで動かせないときは黄色の点線
  - 言葉: 「計器」を「オブジェクト」に、「蓋」を「ふた」にしました
- **使いやすさ**: 保存のメッセージは、.bak を作ったときだけ知らせます。下のメッセージ欄は、カーソルを載せると全文を読めます。ヘルプから説明書とショートカットキーの一覧を開けます
- **不具合の修正**
  - 「既存のパネルからマスターを作る」で、書き方だけ違う同じオブジェクトが 2 つに分かれたり、名前だけ違うオブジェクトが 1 つにまとめられたりしていたのを直しました
  - 新しくパネルを作ったとき、前の車両の RealAnalogGauge の設定が残っていたのを直しました
  - 値に改行が入ると、保存で値が途中で切れていたのを直しました
  - 保存の途中で失敗すると、ファイルが壊れることがあったのを直しました（一時ファイルに書いてから差し替えます）

## 動作環境

- Windows 10 / 11（64bit）
- .NET 10 デスクトップ ランタイム（入っていなければ、起動したときに Windows が入手先を案内します）
- BVE Trainsim 5 / 6 のパネルファイル（Tilt・StopPin・Perspective のキーは BVE 5.8 以降・BVE6。書式 2.00 のパネルでも使えます）

## はじめかた

1. 配布ファイルを好きなフォルダに展開します（`needles`・`needle_E217` フォルダも exe と同じ場所に置いたままにしてください）
2. `BvePanelEditor.exe` を起動します
3. ファイル → 開く で、パネルファイル（.txt / .cfg）を開きます。車両ファイル・シナリオファイルからたどって開くこともできます。パネルファイルを exe や画面にドラッグ＆ドロップしても開けます

開いたばかりのときは「位置ロック」がかかっていて、オブジェクトを不意に動かさないようになっています。パネル画面左上の「🔒 位置ロック中」か Ctrl+L で解除します。選んだオブジェクトの枠は、動かせるときは黄色の実線、動かせないときは黄色の点線です。

## 画面

- **左**: オブジェクトの一覧（ファイル順／レイヤー順）と、問題の一覧
- **中央**: パネル画面（ドラッグで配置、ホイールで拡大、スペース＋ドラッグか右・中ドラッグで表示を動かす、Ctrl+0 で表示範囲の全体を表示。操作の案内は画面の右下）と、パネルファイルのテキスト
- **右**: 選んだオブジェクトのプロパティと、動作プレビュー（速度・圧力などを動かして針や表示灯の動きを確かめる）

## できること

- **見ながら編集**: オブジェクトのドラッグ・矢印キーでの移動、プロパティ欄での値の書き換え、テキストの直接編集。どれも Ctrl+Z で元に戻せます
- **書式を崩さない保存**: コメント・空行・文字コード・改行はそのまま残し、変えた所だけ書き換えます。最初の保存では元のファイルを `.bak` に残します
- **オブジェクトの追加**: 表示灯・指針・デジタル数字・円形ゲージ。標準の針（速度計・圧力計・時計）は回転の中心や角度まで入った状態で置けます。画像・PSD をドロップすると、常点灯画像か、デジタル数字（コマ割済の画像、または 1 コマずつの画像からコマ割を作る）として読み込めます。デジタル数字はテスト画面で 1 コマの高さを確かめられます
- **整理**: 複数選択・整列・グループ化・レイヤーの上げ下げ・名前付け。一覧はファイル順／レイヤー順のボタンで並べ替え。一覧での表示／非表示（パネルくんの画面だけ）と、コメントアウト（BVE でも非表示）
- **動作プレビュー**: 状態量をスライダーで動かし、針の揺れ・表示灯・数字・ゲージを確かめます。昼⇔夜の切り替え、Tilt（傾き）の表示もできます
- **作る**:
  - 新規パネル（ベース画像を選ぶ）
  - 画像からパネルを作る（昼・夜 × 消灯・点灯の 4 枚の画像から、表示灯を切り抜く。窓ガラス・窓枠などの重ねる画像や、スイッチ・カバーの変化を切り抜く部品用の画像も扱えます）
  - PSD から読み込み（レイヤーごとに役割を選ぶ）
  - 指針のふたを作る（パネルの画像から軸のふたを切り抜く）
  - 表示範囲や数字の 1 コマの高さを画像から計算
- **バリエーション展開**: 全部入りのパネル（マスターパネル）を 1 枚作り、オブジェクトごとに入るバリエーション（路線など）を決めて、バリエーションごとのパネルファイルを書き出します。既存のバリエーション別パネルからマスターを作ることもできます。どのバリエーションに入るかは、パネルファイルにコメント `; @group 名前` 〜 `; @end` で書きます
- **RealAnalogGauge 対応**: ATS プラグイン [RealAnalogGauge](https://bvews.jpn.org/materials/real-analog-gauge/)（BVE Workshop 作。目盛が等間隔でない計器の針と、低速の針の振動）の動きを、動作プレビューで再現します（計算は RealAnalogGauge のソース（MIT License）を参考に移植しています。著作権表示は THIRD-PARTY-NOTICES.txt）。設定は車両ファイルの ATS からたどって探すか、手で選びます。一覧では「RAG」の印で分かります。右の欄で 0 からゆっくり動かして針の動きを確かめられ、針の動きの表（入力値と角度）・振動を編集でき、パネル画面のクリックで針の向きを決められます。標準の針と RealAnalogGauge の針は、相互に変換できます
- **問題の一覧**: 画像がない・状態量の書き間違い・使えないキーなどを知らせます。BveEX の状態量（ats256 以上）は「BveEX 対応オブジェクト」として別の印で出します。1 行目の文字コードの指定と中身が違うファイルは、中身の文字コードで読み書きし、警告を出します

細かい動きと主な操作キーは [機能の詳細](docs/機能の詳細.md) を見てください。
`sample` フォルダに、画像・PSD からパネルを作る手順を試せるサンプルと手順書（`sample/Readme.txt`）があります。

## 気をつけること

- 画像の書き出し（表示灯の切り抜き・ふた・PSD からの書き出しなど）は、PNG を上書きすることがあり、Ctrl+Z では戻せません。上書きの前には確認を出します
- パネルファイルを保存しないまま閉じる（終了・別のファイルを開く・新規）と、そのパネルのために新しく書き出した画像（とそのために作ったフォルダ）をゴミ箱に送るか聞きます。すでにあった画像を上書きしたものは対象にしません
- パネルくんはパネルファイルに、グループ・PSD や切り抜き元とのつながりを `;` で始まるコメントで書き込みます（BVE は読み飛ばします）
- 「指針を置く」の一覧は exe と同じフォルダの `needles.txt` に保存します。書き込みできないフォルダ（Program Files など）に置くと保存できません

## 困ったとき

- 予期しないエラーが起きたときは、詳しい内容を `%AppData%\BvePanelEditor\logs` に、まだ保存していない内容の控えを `%AppData%\BvePanelEditor\recovery` に書きます。不具合を知らせるときは、ログのファイルを添えてください
- 表示の設定は `%AppData%\BvePanelEditor\settings.txt` にあります。消すと初期の設定に戻ります
- 版とクレジットは、ヘルプ → バージョン情報 でも見られます
