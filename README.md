# パネルくん

<img width="1748" height="1078" alt="AnimationN2" src="https://github.com/user-attachments/assets/66cf963d-0a86-4bc4-96be-6e7e73711db5" />


BVE Trainsim 5 / 6 の運転台パネルファイル（`BveTs Instrument Panel 2.00 / 2.01`）を、画面で見ながら編集するツールです。

- 版: **0.1α**（試験版です。大事なパネルは、コピーをとってから使ってください）
- ライセンス: MIT License（[LICENSE](LICENSE)）。使っているライブラリ・同梱素材は [THIRD-PARTY-NOTICES.txt](THIRD-PARTY-NOTICES.txt)
- ダウンロード: [Releases](https://github.com/ntfiv/BvePanelEditor/releases) の `BvePanelEditor-0.1alpha-win-x64.zip`（標準の針・サンプルはこちらに入っています。このリポジトリのソースには入っていません）

## 動作環境

- Windows 10 / 11（64bit）
- .NET 10 デスクトップ ランタイム（入っていなければ、起動したときに Windows が入手先を案内します）
- BVE Trainsim 5 / 6 のパネルファイル（Tilt・StopPin・Perspective のキーは BVE 5.8 以降・BVE6。書式 2.00 のパネルでも使えます）

## はじめかた

1. 配布ファイルを好きなフォルダに展開します（`needles`・`needle_E217` フォルダも exe と同じ場所に置いたままにしてください）
2. `BvePanelEditor.exe` を起動します
3. ファイル → 開く で、パネルファイル（.txt / .cfg）を開きます。車両ファイル・シナリオファイルからたどって開くこともできます。パネルファイルを exe や画面にドラッグ＆ドロップしても開けます

開いたばかりのときは「位置ロック」がかかっていて、計器を不意に動かさないようになっています。パネル画面左上の「🔒 位置ロック中」か Ctrl+L で解除します。

## 画面

- **左**: 計器の一覧（ファイル順／レイヤー順）と、問題の一覧
- **中央**: パネル画面（ドラッグで配置、ホイールで拡大）と、パネルファイルのテキスト
- **右**: 選んだ計器のプロパティと、動作プレビュー（速度・圧力などを動かして針や表示灯の動きを確かめる）

## できること

- **見ながら編集**: 計器のドラッグ・矢印キーでの移動、プロパティ欄での値の書き換え、テキストの直接編集。どれも Ctrl+Z で元に戻せます
- **書式を崩さない保存**: コメント・空行・文字コード・改行はそのまま残し、変えた所だけ書き換えます。最初の保存では元のファイルを `.bak` に残します
- **計器の追加**: 表示灯・指針・デジタル数字・円形ゲージ。標準の針（速度計・圧力計・時計）は回転の中心や角度まで入った状態で置けます。画像・PSD をドロップすると、常点灯画像か、デジタル数字（コマ割済の画像、または 1 コマずつの画像からコマ割を作る）として読み込めます。デジタル数字はテスト画面で 1 コマの高さを確かめられます
- **整理**: 複数選択・整列・グループ化・レイヤーの上げ下げ・名前付け。一覧はファイル順／レイヤー順のボタンで並べ替え。一覧での表示／非表示（パネルくんの画面だけ）と、コメントアウト（BVE でも非表示）
- **動作プレビュー**: 状態量をスライダーで動かし、針の揺れ・表示灯・数字・ゲージを確かめます。昼⇔夜の切り替え、Tilt（傾き）の表示もできます
- **作る**:
  - 新規パネル（ベース画像を選ぶ）
  - 画像からパネルを作る（昼・夜 × 消灯・点灯の 4 枚の画像から、表示灯を切り抜く。窓ガラス・窓枠などの重ねる画像や、スイッチ・カバーの変化を切り抜く部品用の画像も扱えます）
  - PSD から読み込み（レイヤーごとに役割を選ぶ）
  - 指針の蓋を作る（パネルの画像から軸の蓋を切り抜く）
  - 表示範囲や数字の 1 コマの高さを画像から計算
- **問題の一覧**: 画像がない・状態量の書き間違い・使えないキーなどを知らせます。BveEX の状態量（ats256 以上）は「BveEX 対応計器」として別の印で出します。1 行目の文字コードの指定と中身が違うファイルは、中身の文字コードで読み書きし、警告を出します

細かい動きと主な操作キーは [機能の詳細](docs/機能の詳細.md) を見てください。
`sample` フォルダに、画像・PSD からパネルを作る手順を試せるサンプルと手順書（`sample/Readme.txt`）があります。

## 気をつけること

- 画像の書き出し（表示灯の切り抜き・蓋・PSD からの書き出しなど）は、PNG を上書きすることがあり、Ctrl+Z では戻せません。上書きの前には確認を出します
- パネルファイルを保存しないまま閉じる（終了・別のファイルを開く・新規）と、そのパネルのために新しく書き出した画像（とそのために作ったフォルダ）をゴミ箱に送るか聞きます。すでにあった画像を上書きしたものは対象にしません
- パネルくんはパネルファイルに、グループ・PSD や切り抜き元とのつながりを `;` で始まるコメントで書き込みます（BVE は読み飛ばします）
- 「指針を置く」の一覧は exe と同じフォルダの `needles.txt` に保存します。書き込みできないフォルダ（Program Files など）に置くと保存できません

## 困ったとき

- 予期しないエラーが起きたときは、詳しい内容を `%AppData%\BvePanelEditor\logs` に、まだ保存していない内容の控えを `%AppData%\BvePanelEditor\recovery` に書きます。不具合を知らせるときは、ログのファイルを添えてください
- 表示の設定は `%AppData%\BvePanelEditor\settings.txt` にあります。消すと初期の設定に戻ります
- 版とクレジットは、ヘルプ → バージョン情報 でも見られます
