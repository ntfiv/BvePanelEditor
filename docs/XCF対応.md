# パネルくんの XCF 対応

パネルくんは GIMP の XCF を**自作の読み込み処理**で読みます（外部ライブラリは使っていません）。

XCF は**読むだけ**で、書き換えることはありません。

記号は ○＝対応、△＝一部・近似、×＝未対応 です。PSD の対応は [PSD対応.md](PSD対応.md) を見てください。

XCF から読み込む画面では、○ のもの（そのまま再現できるマスク・描画モードなどの注記）をレイヤーの行に**青い字**で出し、△・× にあたるもの（近似で再現する描画モード、再現しないレイヤー効果・フォルダの描画モードなど）がある行には、**赤い字**で短い印（△近似・×非対応）を出します。印にマウスを乗せると、詳しい中身がツールチップで出ます。使うレイヤーにそれがあると、下の欄に「元のソフトと見た目が変わるレイヤー N 個」と出ます。

---

## 1. ファイルの形式

| 項目 | 対応 | 補足 |
|---|---|---|
| XCF の版 0〜23（GIMP 2.8・2.10・3.x） | ○ | 版 24 以降は、形式がまだ変わる途中のため「対応していない版です」と知らせて断る |
| RGB | ○ | |
| グレースケール | ○ | 白黒の絵として読む |
| インデックスカラー | × | 「RGB に変換してください」と知らせる |
| 8bit（リニア・sRGB・知覚的） | ○ | 画素の値の解釈は精度の指定に合わせる |
| 16bit・32bit・浮動小数 | × | 「8bit で保存し直してください」と知らせる |
| カラープロファイル（ICC） | △ | 埋め込まれていても色は変換せず、数値をそのまま使う（知らせは出す） |
| 大きなファイル | ○ | 必要なレイヤーだけ読む。読んだ画像は 600MB まで覚えておく |

## 2. 画像データの圧縮

| 方式 | 対応 |
|---|---|
| なし | ○ |
| RLE | ○ |
| zlib | ○ |

## 3. レイヤーの情報

| 項目 | 対応 | 補足 |
|---|---|---|
| 位置と大きさ | ○ | キャンバスの外にはみ出した分も読む |
| レイヤー名 | ○ | |
| 表示・非表示 | ○ | 一覧の初期値や役割の初期値に使う。重ねるときは、選んだレイヤーなら非表示でも重ねる |
| 不透明度 | ○ | |
| フォルダ（グループ） | ○ | 入れ子も読む。開いた・閉じた状態も引き継ぐ |
| フォルダの描画モード | × | 「通過」として扱う。通過以外は再現せず、重ねるときに警告する（PSD と同じ扱い） |
| レイヤーマスク | ○ | 「マスクを使わない」の設定も見る。フォルダのマスクは中のレイヤー全部に掛ける |
| 文字レイヤー | ○ | GIMP が持っている画素の絵を使う（文字を描き直さない。フォント情報は扱わない） |
| ロック（透明部分・内容・位置） | 無視 | |
| 浮動選択 | × | 読み飛ばして知らせる |
| チャンネル・パス・選択範囲 | 無視 | パネル作りには使わない |
| 同じ場所に同じ名前のレイヤー | ○ | 上（手前）から 2 枚目以降を「名前 #2」「名前 #3」…と区別する（PSD と同じ） |

## 4. レイヤー効果（GIMP 3 の非破壊フィルター）

| 項目 | 対応 | 補足 |
|---|---|---|
| レイヤー効果（ぼかしなど） | × | 再現しない。付いているレイヤーには知らせを出す（黙って消えることはない） |

GIMP で効果を確定させたいときは、レイヤーを画像化（ラスタライズ）してから保存してください。

## 5. 描画モード

XCF の描画モードは PSD の描画モードの式に写して計算します。合成の色空間は GIMP に合わせ、**版 10 以降（GIMP 2.10 世代）のファイルはリニアの明るさで合成**します（モードによっては sRGB で計算するものもあり、GIMP と同じ使い分けをします。旧方式のモードは常に sRGB で計算します）。

| 描画モード | 対応 | 補足 |
|---|---|---|
| 通常（標準・旧） | ○ | |
| 乗算・スクリーン・オーバーレイ・加算・減算・比較（暗）・比較（明）・差の絶対値・覆い焼き・焼き込み（標準・旧とも） | ○ | GIMP の書き出し画像とピクセル単位で一致を確認済み |
| 除算・ハードライト・ビビッドライト・リニアライト・ピンライト・ハードミックス・除外・焼き込み（リニア） | ○ | |
| ソフトライト（標準・旧） | △ | 式が GIMP と少し違うため近似。知らせを出す |
| 色相（HSV、標準・旧） | △ | 式が GIMP と少し違うため近似。知らせを出す |
| 色相・彩度・カラー・輝度（LCh 系）・カラー比較（暗）・カラー比較（明） | △ | PSD の HSV 系の式で近似。知らせを出す |
| 彩度・カラー・値（HSV 系） | △ | 近似。知らせを出す |
| ディザ合成 | △ | 通常として重ね、注意を出す |
| 背後・穀物（抽出・マージ）・色消去・消去・結合・分割 ほか、写せないモード | × | 通常として重ね、知らせを出す |

表示灯・数字のコマとして 1 枚ずつ切り出すときは、そのレイヤー自身の描画モードは通常として扱います（PSD と同じ。BVE は通常で描くため）。

## 6. 統合画像

XCF には全体を重ねた絵（統合画像）が**入っていません**。PSD の統合画像の代わりに使う場面（「画像からパネルを作る」で 1 枚の絵として使うときなど）では、表示中のレイヤーを重ねた絵を使います。

## 7. GIMP との違いの目安

GIMP 3 で作った検証用ファイルで、パネルくんで重ねた絵と GIMP が書き出した絵を比べた結果です（色の差の平均、0〜255）。単体テストの `XcfRealFileTests`（`BVE_XCF_DIR` を設定したときだけ動く）と手元の照合で確かめています。

| ファイル | 差 | 補足 |
|---|---|---|
| 基本（はみ出し・不透明度・非表示） | 0.00 | |
| 描画モード 15 種 | 0.69 | 15 種中 13 種が完全一致。残りはソフトライト（8.9）と色相 HSV（4.8）で、式の違い（△ で知らせる） |
| マスク | 0.00 | |
| 文字レイヤー | 0.00 | |
| パネル風（昼夜フォルダ・1024×768） | 0.00 | |
| フォルダ（乗算） | 16.53 | フォルダの描画モードが再現できないため（× で知らせる） |
