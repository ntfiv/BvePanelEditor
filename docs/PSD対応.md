# パネルくんの PSD 対応

パネルくんは PSD を**自作の読み込み処理**で読みます（外部ライブラリは使っていません）。

PSD は**読むだけ**で、書き換えることはありません。

この文書は 0.2α に合わせています。記号は ○＝対応、△＝一部・近似、×＝未対応 です。

---

## 1. ファイルの形式

| 項目 | 対応 | 補足 |
|---|---|---|
| PSD（版 1） | ○ | |
| PSB（大きなドキュメント形式、版 2） | × | 「PSD で保存し直してください」と知らせる |
| RGB | ○ | |
| グレースケール | ○ | 白黒の絵として読む |
| CMYK・Lab・インデックスカラー・白黒 2 階調・ダブルトーン・マルチチャンネル | × | 「RGB に変換してください」と知らせる |
| 8bit | ○ | |
| 16bit | ○ | 8bit に丸めて使う |
| 1bit・32bit | × | |
| カラープロファイル（ICC） | 無視 | 色は変換せず、数値をそのまま使う |
| 大きなファイル | ○ | ファイルを全部は読み込まず、必要なレイヤーだけ読む。読んだ画像は 600MB まで覚えておく |

| 方式 | レイヤー | 統合画像 |
|---|---|---|
| 無圧縮 | ○ | ○ |
| RLE（PackBits） | ○ | ○ |
| ZIP（予測なし） | ○ | ○ |
| ZIP（予測付き） | ○ | ○ |

## 3. レイヤーの情報

| 項目 | 対応 | 補足 |
|---|---|---|
| 位置と大きさ | ○ | |
| レイヤー名 | ○ | Unicode の名前（`luni`）を使う。なければ Shift-JIS として読む |
| 表示・非表示 | ○ | 一覧の初期値や役割の初期値に使う。重ねるときは、選んだレイヤーなら非表示でも重ねる |
| 不透明度 | ○ | |
| 塗りの不透明度 | ○ | 不透明度と掛け合わせる（通常の描画モードなら Photoshop と同じ） |
| フォルダ（グループ） | ○ | 入れ子も読む。開いた・閉じたフォルダのどちらも |
| フォルダの不透明度 | ○ | 中のレイヤーそれぞれに掛ける（中のレイヤーどうしが重なる所は Photoshop と少し違うことがある） |
| フォルダの描画モード | △ | 「通過」として扱う。通過以外（フォルダを 1 枚にまとめてから合成）は再現しない |
| レイヤーマスク（ピクセルのマスク） | ○ | 範囲外の色・「使わない」の設定も見る |
| フォルダのマスク | ○ | 中のレイヤー全部（調整レイヤー・べた塗りも）に掛ける |
| 調整レイヤー・べた塗りのマスク | ○ | |
| マスクの濃度・ぼかし | × | |
| ベクトルマスク | × | 無視される |
| クリッピングマスク | ○ | すぐ下のクリッピングされていないレイヤーの形で切り抜く |
| フォルダへのクリッピング | ○ | フォルダの中で表示されているものを重ねた形で切り抜く（フォルダのマスクも含む） |
| ブレンド条件（「このレイヤー」「下になっているレイヤー」） | × | |
| 同じ場所に同じ名前のレイヤー | ○ | 上（手前）から 2 枚目以降を「名前 #2」「名前 #3」…と区別する |

## 4. レイヤーの種類

| 種類 | 対応 | 補足 |
|---|---|---|
| 画像レイヤー | ○ | |
| テキストレイヤー | ○ | PSD に入っているラスタライズ済みの絵を使う（文字を描き直さない） |
| スマートオブジェクト | ○ | PSD に入っている表示用の絵を使う（中身の PSD を開き直したり、変形をかけ直したりしない） |
| べた塗りレイヤー | ○ | RGB かグレーの色。マスクで形を付ける |
| グラデーション・パターンの塗りつぶしレイヤー | × | 一覧に「重ねられません」と出る |
| 調整レイヤー | △ | 次の表のとおり |
| 中身のないレイヤー（大きさ 0） | × | 一覧に「重ねられません」と出る |

### 調整レイヤー

調整レイヤーは、その下に重ねた絵の色を変えます。不透明度・マスク・フォルダのマスク・クリッピングの分だけ効きます。
描画モードは通常として扱います。

| 調整レイヤー | 対応 | 補足 |
|---|---|---|
| レベル補正 | ○ | RGB と R・G・B それぞれ（入力の黒・白、ガンマ、出力の黒・白）。色ごとの補正の後に RGB の補正をかける |
| トーンカーブ | ○ | RGB と R・G・B それぞれ。点の間は滑らかな曲線（3 次スプライン）でつなぐ。鉛筆で描いたカーブにも対応 |
| 明るさ・コントラスト（従来方式） | ○ | |
| 明るさ・コントラスト（今の方式） | △ | Photoshop の式が公開されていないので近似。重ねるときに注意を出す |
| 色相・彩度 | △ | マスター（全体）の色相・彩度・明度と「色彩の統一」。近似なので注意を出す。色ごと（レッド系など）の調整は反映しない |
| 上記以外（カラーバランス、露光量、自然な彩度、チャンネルミキサー、白黒、グラデーションマップ、特定色域の選択、レンズフィルター、カラールックアップ、階調の反転、ポスタリゼーション、2 階調化） | × | 一覧に「重ねられません」と出る。効果はかからない |

調整レイヤーが効くのは、レイヤーを重ねて 1 枚にするとき（PSD から読み込むの「ベース」、画像からパネルを作るの各欄）です。
PSD から読み込むで「表示灯」「数字のコマ」として 1 枚ずつ切り出すときは、下の絵がないので効きません（そのレイヤーにクリッピングした調整レイヤーは効きます）。

## 5. 描画モード

| 描画モード | 対応 |
|---|---|
| 通常・通過 | ○ |
| ディザ合成 | △（通常として重ね、注意を出す） |
| 比較（暗）・乗算・焼き込みカラー・焼き込み（リニア）・カラー比較（暗） | ○ |
| 比較（明）・スクリーン・覆い焼きカラー・覆い焼き（リニア）- 加算・カラー比較（明） | ○ |
| オーバーレイ・ソフトライト・ハードライト・ビビッドライト・リニアライト・ピンライト・ハードミックス | ○ |
| 差の絶対値・除外・減算・除算 | ○ |
| 色相・彩度・カラー・輝度 | ○ |

Photoshop の描画モードは全部再現します（ディザ合成を除く）。式は一般に知られているもの（色相・彩度・カラー・輝度は W3C の合成の仕様と同じ式）を使っています。

表示灯（PSD から読み込むの「表示灯」）として 1 枚ずつ切り出すときは、そのレイヤー自身の描画モードは通常として扱います（BVE は通常で描くため）。上にクリッピングされたレイヤーの描画モードは再現します。

## 6. レイヤー効果

レイヤー効果は、パターンを使うもの以外は再現します。
ただし Photoshop の式は公開されていないので、ぼかしの形やベベルの陰影は**近似**です（形・位置・色・不透明度・描画モードは合わせています）。
近似のものや再現しないものがあるときは、重ねる・書き出すときに注意を出します。正確に合わせたいときは、Photoshop でレイヤーをラスタライズ（効果を含めて画像にする）してから使ってください。

| 効果 | 対応 | 補足 |
|---|---|---|
| ドロップシャドウ | △ | 色・描画モード・不透明度・角度・距離・スプレッド・サイズ。ぼかしは近似 |
| 光彩（外側） | △ | 色（グラデーションなら最初の色）・スプレッド・サイズ。ぼかしは近似 |
| シャドウ（内側） | △ | 色・角度・距離・チョーク・サイズ。ぼかしは近似 |
| 光彩（内側） | △ | 境界から／中央から・チョーク・サイズ。ぼかしは近似 |
| ベベルとエンボス | △ | 内側・外側・エンボス・ピローエンボス（境界線エンボスは内側として扱う）、深さ・方向・サイズ・ソフト、ハイライトとシャドウの色・描画モード・不透明度、光源の角度と高度。陰影の付き方は近似 |
| サテン | △ | 色・角度・距離・サイズ・反転。近似 |
| カラーオーバーレイ | ○ | |
| グラデーションオーバーレイ | △ | 線形・円形・角度・反射・菱形、角度・比率・逆方向・レイヤーに揃える・位置のずらし、色と不透明度の分岐点・中間点。範囲の取り方は近似。ノイズのグラデーションは × |
| 境界線 | ○ | 外側・内側・中央、サイズ、カラーまたはグラデーション。パターンは × |
| パターンオーバーレイ | × | |
| 輪郭（コンター）・ノイズ・ジッター | × | 輪郭は直線として扱う |
| フォルダのレイヤー効果 | × | フォルダを 1 枚にまとめてから効果をかける作りは再現しない |
| 古い形式の効果（`lrFX` だけのもの） | × | |

共通:
- 「包括光源を使用」の効果は、PSD 全体の光源（角度・高度）を使う
- 効果は「塗りの不透明度」の影響を受けない（Photoshop と同じ）。レイヤーの不透明度とフォルダの不透明度は掛かる
- 効果の重なり順は Photoshop と同じ（下から: ドロップシャドウ、光彩（外側）、レイヤー本体、シャドウ（内側）、光彩（内側）、ベベル、サテン、カラー、グラデーション、境界線）
- 「マスターの効果のオン・オフ」と、効果ごとのオン・オフを見る
- 表示灯・数字のコマとして切り出すときは、影や光彩が広がる分だけ範囲を広げて切り出す

**Photoshop との見比べについて**: 手元の PSD では、効果のあるレイヤーがどれも非表示のフォルダの中にあり、統合画像と見比べられませんでした。効果の再現度は、合成した画像での単体テストと、目で見た確認だけです。

## 7. 統合画像

PSD 全体を重ねた絵（統合画像）は、次のときに使います。

- 「画像からパネルを作る」で、PSD を 1 枚の絵として使うとき
- PSD の読み込み画面で、レイヤーを重ねた結果と見比べるとき

Photoshop で「互換性を優先」をオフにして保存した PSD では、統合画像が白や空のことがあります。

## 8. Photoshop との違いの目安

手元の PSD で、表示中のレイヤーをパネルくんで重ねた絵と、Photoshop が保存した統合画像を比べた結果です（色の差の平均、0〜255）。
単体テストの `PsdRealFileTests`（`BVE_PSD_DIR` を設定したときだけ動く）で確かめています。

| PSD | 差 | 補足 |
|---|---|---|
| 見本 A（昼）／（夜） | 0.12 ／ 0.01 | |
| 見本 B（発光） | 0.06 | フォルダのマスク・彩度の描画モードを使っている |
| 見本 B（パネル本体） | 0.58 | 焼き込みカラー・調整レイヤーを使っている |
| 見本 B のほかの PSD | 0.00〜0.01 | |
| 見本 B（操作の表示） | 6.11 | 黒地に白い文字だけの小さな PSD。文字のふちが Photoshop のほうが明るい（Photoshop の「テキストカラーをガンマでブレンド」の設定によるものと思われる） |

## 9. 手元の PSD で使われているレイヤー効果

作者の手元の PSD を読むだけで調べた結果です。

| PSD | レイヤー効果 |
|---|---|
| 見本 B（パネル本体） | 199 枚。ドロップシャドウ 95、ベベルとエンボス 85（内側 43・ピロー 36・外側 6）、サテン 41、グラデーションオーバーレイ 26、カラーオーバーレイ 22、境界線 2、シャドウ（内側）1。**どれも再現できる種類**。フォルダのレイヤー効果（古い形式）3 つだけ再現しない |
| 見本 A（夜） | 1 枚（速度計シール）。効果はすべてオフになっている |
| ほかの PSD | なし |

どれも 8bit の RGB で、PSB・CMYK・16bit のものはありませんでした。

## 開発者向け: コードの場所

`src/BvePanelEditor.Core/Psd/` にあります。

| ファイル | 役目 |
|---|---|
| `PsdFile.cs` | PSD を読む（ファイルの形式、レイヤー、フォルダ、マスク、画像データ、統合画像） |
| `PsdCompose.cs` | 選んだレイヤーを重ねて 1 枚の絵にする（不透明度、マスク、クリッピング、描画モード、べた塗り、調整レイヤー） |
| `PsdAdjust.cs` | 調整レイヤーの色の変え方 |
| `PsdEffects.cs` | レイヤー効果を読む・描く |
| `PsdDescriptor.cs` | PSD の「記述子」を読む（べた塗りの色、明るさ・コントラストの値など） |
| `PngWriter.cs` | PNG を書き出す（パネルくんが書いた印を入れる） |
