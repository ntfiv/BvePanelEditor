# パネルくん　開発者向け

C# / .NET 10 + WPF。ソースは MIT License（[LICENSE](../LICENSE)）。

## ビルドと起動

.NET 10 SDK が必要です。

```
dotnet run --project src/BvePanelEditor
```

ビルドした exe は `src/BvePanelEditor/bin/Debug/net10.0-windows/BvePanelEditor.exe`（ファイルをドラッグ＆ドロップしても開けます）。

### 配布用のビルド

```
dotnet publish src/BvePanelEditor -c Release -r win-x64 --self-contained false -o publish
```

- `-c Release` では、確認用の起動オプション（下）と、その中身のファイル（`MainWindow.*Test.cs`）を入れません。
- .NET を同梱して、.NET のインストールなしで動かすときは `--self-contained true`（大きくなります）。
- 出力に入るもの: exe・dll、`needles`（標準の針、CC0）、`needle_E217`（E217 の針と出典の Readme）、`LICENSE.txt`、`THIRD-PARTY-NOTICES.txt`、`はじめにお読みください.txt`。

## 構成

| 場所 | 中身 |
|---|---|
| `src/BvePanelEditor.Core` | パネルファイルの読み書き（`PanelDocument`）、キーの定義（`PanelSpec`）、状態量（`Subjects`）、車両・シナリオ（`BveFiles`）、PSD・切り抜き・Tilt の計算 |
| `src/BvePanelEditor` | WPF 画面。描画と配置操作は `Rendering/PanelCanvas.cs` |
| `tests/BvePanelEditor.Tests` | 読み書きなどのテスト（`dotnet test`）。`BVE_PANEL_DIR` を設定すると、その下の全パネルで読み書き一致を確かめる。`BVE_VARIATION_MASTERS`（; 区切り）を設定すると、そのパネル（`; @group` の印の付いたマスター）の読み書き一致を確かめる |
| `free_needle` | 標準の針の画像（CC0）。exe の `needles` フォルダに入る |
| `needle_E217` | E217 の針の画像（内房線製作チーム）。exe の `needle_E217` フォルダに入る |
| `docs` | [機能の詳細](機能の詳細.md)、[PSD 対応](PSD対応.md) |

公開しているソースには、針の画像（`free_needle`・`needle_E217`）とサンプル（`sample`）は入っていません。なくてもビルドはできます（「指針を置く」の標準の針が使えないだけ）。使うときは、配布版の `needles`・`needle_E217`・`sample` フォルダをそれぞれ `free_needle`・`needle_E217`・`sample` としてリポジトリの直下に置いてください。

## 設定・ログの置き場所

- `%AppData%\BvePanelEditor\settings.txt` … 表示の設定（画面枠の比率・揺れの余白・一覧の並び順）
- `%AppData%\BvePanelEditor\crop_panels.txt` … 画像から作ったパネルの場所
- `%AppData%\BvePanelEditor\logs\` … 予期しないエラーのログ
- `%AppData%\BvePanelEditor\recovery\` … 予期しないエラーのときの、未保存の内容の控え
- exe と同じフォルダの `needles.txt` … 「指針を置く」の一覧

## 確認用の起動オプション（デバッグ版だけ）

```
BvePanelEditor.exe <ファイル> --selftest 結果.txt
```

開いたパネルに対して、選択・プロパティ変更・追加・複製・削除・並べ替え・元に戻す・テキスト編集・保存を自動で通し、結果を書いて終了します。**保存もするので、必ずコピーに対して使ってください。**

- `--croptest 昼・無発光.png 作業フォルダ 結果.txt` … 画像からパネルを作る流れ（元の画像は読むだけ）
- `--croppsdtest パネル.psd 作業フォルダ 結果.txt` … PSD のレイヤーを 4 点に振り分けてパネルを作る
- `--cropoverlaytest 昼・無発光.png 作業フォルダ 結果.txt` … 重ねる画像・部品用
- `--psdtest 昼.psd 夜.psd(または -) 作業フォルダ 結果.txt` … PSD の読み込み・保存
- `--digitimporttest 作業フォルダ 画面.png 結果.txt` … 画像・PSD を常点灯画像・デジタル数字（コマ割済・単コマ）として読み込む
- `--trashtest 作業フォルダ 結果.txt` … 保存しないで閉じるときに、書き出した画像をゴミ箱に送るか聞く（ゴミ箱には送らず消す）
- `--variationtest 作業フォルダ 画面.png 結果.txt` … バリエーション展開（一覧・表示の切り替え・目のマーク・チェック・書き出し・既存のパネルから作る）
- `--grouptest 作業フォルダ 画面.png 結果.txt` … グループの入れ子（クリック・ダブルクリック・一覧の字下げ・折りたたみ・並べ替え・複製・保存）
- `--spacepantest 作業フォルダ 結果.txt` … スペース＋左ドラッグ・右・中ドラッグで表示を動かす
- `--ragtest 作業フォルダ 結果.txt` … RealAnalogGauge（車両の ATS から設定を探す・プレビューの計算・ゆっくり動かす・表の編集と保存・標準の針との相互変換）。画面は 結果.png・結果.edit.png・結果.sweep.png
- `--memtest 見本のフォルダ 作業フォルダ 結果.txt` … 画像からパネルを作る画面の開け閉め・画像や PSD の読み込みをくり返しても、メモリが増え続けないか（見本のフォルダは sample\PNG_to_panel。隣に PSD_to_panel があれば PSD も）
- `--mainpaneltest 2つ目のパネル 画面.png 結果.txt`、`--covertest`、`--needletest`、`--hiddentest`、`--disabledtest`、`--listordertest`、`--tilttest`、`--crashtest` など（`App.xaml.cs` を参照）
- `--snapshot 画面.png`（画面を保存して終了）、`--view x,y,倍率`、`--state kmph=60;bc=300;lamps=0;night=0.5;tab=1`、`--select 番号`

デバッグ版・リリース版とも、Ctrl+9 で画面に出すパスをファイル名だけにする・戻す（画面写真を撮るときの確認用。覚えておかない）。

確認用の起動では、針の一覧（needles.txt）は一時フォルダに作り、予期しないエラーはメッセージを出さずに `%TEMP%\panelkun_error.txt` に書いて終わります。
